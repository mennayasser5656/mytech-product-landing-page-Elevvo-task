# MyTech — Product Landing Page

A responsive SaaS product landing page built with semantic HTML, custom CSS, and vanilla JavaScript. This portfolio practice project demonstrates a modern product marketing page with feature highlights, testimonials, pricing plans, and interactive UI elements.

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Light and dark theme toggle with saved preference
- Product dashboard illustration built with HTML and CSS
- Feature cards and customer testimonials
- Three pricing plans with interactive selection feedback
- Smooth in-page navigation and accessible focus styles
- Reduced-motion support
- Dynamic copyright year

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Google Fonts (DM Sans and Manrope)

## Run locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, `script.js`, and `README.md` in the same folder.
3. Open `index.html` in your browser.

No build tools or frameworks are required. An internet connection is needed to load Google Fonts; the main layout and dashboard illustration are created with HTML and CSS.

## Publish with GitHub Pages

1. Upload the project files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder, then click **Save**.

## Note

This is a front-end demo. Pricing buttons only show a plan-selection message; they do not create accounts or process payments. Testimonials and pricing are sample content.
